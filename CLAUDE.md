## Project Overview
Unity 6 (6000.3.x) project using the Universal Render Pipeline (URP) and the new Input System.
This proyect is a 2D top down delivery game where a car need to deliver packages to random selected locations where the clients reside. 

## Structure
- `Assets/` — all game scripts, scenes, and assets
- `Packages/` — Unity package manifest
- `ProjectSettings/` — Unity project settings (version control these)
- `Library/`, `Temp/` — generated, do not edit or commit

## Language & Conventions
- C# with `LangVersion 9.0` (Unity constraint)
- `netstandard2.1` target framework
- Assembly: `Assembly-CSharp`
- Do not use `AllowUnsafeBlocks` (disabled in project)

## Key Notes
- Do not modify `Assembly-CSharp.csproj` — it is auto-generated by Unity
- Prefer Unity's new Input System (`InputSystem_Actions.inputactions`) over the legacy Input API
- URP is configured; avoid adding Built-in RP specific code
- Scripts live in `Assets/` — Unity requires this for compilation
